# 司馬遷 — 歴史を書いた人の物語（地図・挿絵・写真入り版）

『和氏の璧』から中島敦『李陵』へ進むための、歴史・地理の教材です。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 教材本体（7章） |
| `historymap.js` | 歴史地図（地点・経路・勢力圏・李陵事件の進行。すべて緯度経度で管理） |
| `assets/geodata.js` | 地形データ（Natural Earth を簡略化。海岸線・河川・湖・砂漠・山脈） |
| `assets/ill-0.svg`〜`ill-6.svg` | 各章の挿絵（この教材のために描いた想像図） |
| `assets/three-positions.webp` | 挿絵「李陵事件：三者の立場」 |
| `vendor/leaflet/` | 地図ライブラリ Leaflet 1.9.4（BSD 2-Clause） |
| `icon.png` / `.nojekyll` | アイコン / GitHub Pages 用 |

## 公開（GitHub Pages）

1. このフォルダの中身を**すべて**（`assets`・`vendor` フォルダと `.nojekyll` を含む）リポジトリのルートに置く。
2. Settings → Pages → Deploy from a branch → main / (root)。

インターネットなしでも、ファイルを直接開いても地図と挿絵は表示されます。現在の写真と「現代の地図を重ねる」は接続が必要です。

## 地図について

- 第三展示室：世界 → ユーラシア → 東アジア → 李陵の戦場を、一枚の同じ地図で拡大する。
- 第三展示室「同じころ、世界と日本では」：前283年・前221年・前200年・前99年・後57年・後239年の六つの時代を選ぶと、地図上の国名と、五つの地域（中国・草原・西アジア・地中海・日本列島）の説明が切り替わる。各時代に「つながりを確かめる」欄があり、直接の関係／人や物を介した関係／同じ時代だが関係は確かめられない、の三つに分けて示す。前300年〜後300年の年表つき。
- 第一展示室：『和氏の璧』を7つの場面でたどる。戦国七国のおおよその範囲、邯鄲と咸陽の距離、藺相如と璧が別々の道を通ったことを地図上で再生する。
- 最終展示室「漢文の味わい」：『史記』の原文から七つの言葉を選び、白文・書き下し文・現代語訳・味わいどころ・句法を示す。各項目から第一展示室の地図の該当場面へ移れる。
- 第四展示室：李陵事件を8つの場面でたどる。軍の移動と、知らせが長安へ届く動きを地図上で再生する。
- どちらの地図も、再生は一場面ごとに止まる（「通して再生」も選べる）。場面ごとに三人の状況が並んで表示され、「くらべてみよう」の問いと、だれが何を知っていたかを一覧にした「三人の時間表」が付く。
- 史料上の確かさを区別している。黒丸＝位置が確かな地点（長安、居延、河西回廊の郡）。点線の丸・円＝推定（浚稽山、降伏の地、単于の本拠、天山）。点線＝推定の経路。
- できごと・兵数は『漢書』（李広蘇建伝の李陵の部分、司馬遷伝）と「報任安書」による。行軍の道筋は史料から特定できないため、すべて推定として描いている。
- 漢と匈奴の色の帯は、前100年ごろのおおよその広がりで、国境線ではない。

## 挿絵と写真

- 挿絵は全7章に1枚ずつ（第四展示室は2枚）。すべて想像図で、「挿絵・想像図」の札を付けている。
- 現在の写真は16点。Wikimedia Commons の画像を、同サイトから直接表示している（ファイルは同梱していない）。「現在の写真」の札と、撮影者・ライセンス・出典へのリンクを各写真に付けている。
- 地図の地点（長安・居延・敦煌・浚稽山・降伏の地・単于の本拠）を押すと、説明と写真が出る。位置が推定の地点には、その場所そのものの写真ではないことを明記している。
